# JH / PAPER LOG

An editorial research index for paper notes on antennas, electromagnetics, inverse design, and AI-assisted RF design.

The site is plain HTML, CSS, and JavaScript, so it can be served directly with GitHub Pages. Paper content lives in `papers.js`; cards, filters, counts, topic totals, and the current-focus panel are generated automatically.

See [README-KO.md](README-KO.md) for the editing guide.
