# JH / PAPER LOG

An editorial research index for paper notes on antennas, electromagnetics, inverse design, and AI-assisted RF design.

The site is plain HTML, CSS, and JavaScript, so it can be served directly with GitHub Pages. The library intentionally starts empty and shows its first card after a real paper note is added to `index.html`.

See [README-KO.md](README-KO.md) for the editing guide.
