# JH / PAPER LOG

An editorial research index for paper notes on antennas, electromagnetics, inverse design, and AI-assisted RF design.

The site is plain HTML, CSS, and JavaScript, so it can be served directly with GitHub Pages. Paper metadata lives in `papers.js`; cards, filters, counts, and topic totals are generated automatically, while notes can use any external or local format through `noteUrl`.

See [README-KO.md](README-KO.md) for the editing guide.
