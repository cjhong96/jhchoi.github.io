# JH / PAPER LOG

An editorial research index for paper notes on antennas, electromagnetics, inverse design, and AI-assisted RF design.

The site is plain HTML, CSS, and JavaScript, so it can be served directly with GitHub Pages. Each paper lives in its own module under `papers/`; `papers/index.js` registers the files, and cards, filters, counts, and topic totals are generated automatically.

See [README-KO.md](README-KO.md) for the editing guide.
