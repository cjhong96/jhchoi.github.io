# JH / PAPER LOG

An editorial research index for paper notes on antennas, electromagnetics, inverse design, and AI-assisted RF design.

The site is plain HTML, CSS, and JavaScript, so it can be served directly with GitHub Pages. Each paper keeps its card metadata in `papers/<slug>.js` and its free-form long review in the matching `reviews/<slug>.md`. The shared review reader supports Markdown, figures, code blocks, tables, and KaTeX equations without requiring a per-paper URL field.

See [README-KO.md](README-KO.md) for the editing guide.
