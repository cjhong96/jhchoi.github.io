# JH / PAPER LOG

A research paper review archive for antennas, electromagnetics, inverse design, and AI-assisted RF design. Search, status filters, and the tag index are generated from the Markdown files.

The site is plain HTML, CSS, and JavaScript, so it can be served directly with GitHub Pages. Each `papers/<paper name>.md` file contains Obsidian-compatible properties and the free-form review body; its exact filename without `.md` is registered in `papers/index.txt`. The shared reader supports Markdown, figures, code blocks, tables, and KaTeX equations without requiring per-paper JavaScript or URL fields.

See [README-KO.md](README-KO.md) for the editing guide.
