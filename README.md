# JH / PAPER LOG

An editorial research index for paper notes on antennas, electromagnetics, inverse design, and AI-assisted RF design.

The site is plain HTML, CSS, and JavaScript, so it can be served directly with GitHub Pages. Authors edit one file per paper: `papers/<slug>.md` contains a small metadata header and the free-form review body. The shared reader supports Markdown, figures, code blocks, tables, and KaTeX equations without requiring per-paper JavaScript or URL fields.

See [README-KO.md](README-KO.md) for the editing guide.
